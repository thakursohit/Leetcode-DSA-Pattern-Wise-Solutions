This specific problem is a classic application of the Two-Pointer Technique.Here are the formal notes for Segregating 0s and 1s.📘 Topic: Segregating 0s and 1s (Two-Pointer Pattern)1. Problem StatementGiven an array containing only 0s and 1s, rearrange the array so that all zeros appear first, followed by all ones. The solution must be in-place (using no extra memory).2. Efficiency AnalysisTime Complexity: $O(n)$We traverse the array only once. Even though we have two pointers, the "explorer" pointer only visits each element a single time.Space Complexity: $O(1)$We do not use any extra arrays or data structures; we only swap elements within the existing memory.3. Core Logic: The "Boundary" MethodThe most robust way to solve this is to treat the array like it has a moving wall.Left Pointer (left): Represents the boundary of the 0s. Everything to the left of this pointer is confirmed to be a 0.Right Pointer (right): The explorer. It scans every element from index $0$ to $n-1$.The Rule:Whenever the explorer finds a 0, it swaps that value with whatever is at the left boundary. Then, the boundary moves one step to the right.4. Implementation (C++)C++void segregate0and1(vector<int> &arr) {
    int left = 0; // The "0" boundary
    
    for (int right = 0; right < arr.size(); right++) {
        if (arr[right] == 0) {
            // Found a zero! Swap it to the front boundary
            swap(arr[left], arr[right]);
            left++; // Move the boundary forward
        }
    }
}
